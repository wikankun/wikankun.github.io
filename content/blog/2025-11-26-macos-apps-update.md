After a year using apps in [[2024-12-30-macos-apps]], I found that not every app works for me. Here's a list of new apps that increase my productivity even more:

1. [Jordan Baird's Ice](https://icemenubar.app/)

    Ice is a powerful menu bar management tool.
    While its primary function is hiding and showing menu bar items, it aims to cover a wide variety of additional features to make it one of the most versatile menu bar tools available.
    It's a better replacement for Hidden Bar.

2. [Kaleidoscope](https://kaleidoscope.app/)

    A diff and merge tool that deeply integrates with Git.
    The File History lets you browse and compare all revisions of a file.
    Details about each commit help you understand context and take action.

3. [Obsidian](https://obsidian.md/)

    Obsidian is a powerful note-taking app that allows you to create and organize notes in a simple and intuitive way.
    It provides a variety of features such as markdown support, tagging, and linking.
    It also integrates with other tools such as GitHub and Dropbox.

4. [Orbstack](https://orbstack.dev/)

    OrbStack is the fast, light, and easy way to run Docker containers and Linux.
    A better Docker Desktop alternative for macOS.

5. [Orion](https://orionbrowser.com/)
    
    A web browser designed from the ground-up.
    Native WebKit speed, full extension compatibility, and absolute privacy is finally together in one browser that respects you.

6. [Runcat](https://kyome.io/runcat/index.html)

    RunCat provides a key-frame animation to the menu bar. Animation changes the speed depending on the CPU usage of Mac.

7. [Cyberduck](https://cyberduck.io/)

    Cyberduck is a powerful FTP, SFTP, WebDAV, S3, Backblaze B2, Azure, and OpenStack Swift browser for Mac, Windows, and Linux.
    It supports a wide range of protocols and provides a user-friendly interface for managing files and folders.

8. [Zed](https://zed.dev/)

    Zed is a next-generation code editor designed for high-performance collaboration with humans and AI.
    It focuses on speed, built-in collaboration features like real-time multiplayer editing, and AI integrations, such as delegating tasks to AI agents.

9. [Claude Code](https://www.claude.com/product/claude-code/)

    Unleash Claude's raw power directly in your terminal or IDE.
    Work with Claude directly in your terminal. Claude explores your codebase context, answers questions, and make changes. It can even use all your CLI tools.
